# 内容配置管理原型设计

管理端平台管理员及内容管理员侧栏末尾增加“配置管理”一级抽屉，包含“栏目管理”和“敏感词库”两个二级页面。栏目管理维护职工发帖可选择的分类，支持新增、改名、排序和启停；回音壁是系统公开答复栏目，不开放职工发帖。关闭栏目停止新的发帖选择，历史帖子保持可见。敏感词库支持新增、编辑、启停及作用范围（发帖、评论、全部）。

共享浏览器演示数据新增栏目及敏感词数组，兼容已有 localStorage 数据，不清空帖子和事项。职工端“我要发言”提供标题、栏目、正文表单，发帖前检查栏目是否可用及标题/正文是否命中启用词；评论提交前检查内容是否命中。命中时提示不能提交，输入保留供修改，违规文本不写入帖子、评论或审计记录；通过的内容进入原有待审核队列。敏感词匹配为本地不区分英文字母大小写的直接包含匹配，仅供原型演示，正式系统需服务端再次校验。
