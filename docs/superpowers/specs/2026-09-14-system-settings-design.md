# 管理端系统设置导航设计

平台管理员侧栏保留运营工作台、内容治理、事项办理、整改与公开、内容运营及独立数据统计。新增位于工作总览之后的可展开“系统设置”一级菜单，内含用户管理、组织架构、角色管理、系统日志、审计与安全五个二级页面。默认收起；点击后展开或再次收起。其他角色的侧栏不变。

用户管理沿用注册审核和账户数据；组织架构按省社本级、直属单位和市州社层级展示演示结构，不伪称已接入真实组织目录；角色管理沿用现有五角色权限矩阵并明确配置仅为展示；系统日志读取共享演示数据的操作记录；审计与安全展示审计边界及安全策略要求，不伪造访问记录或真实安全策略写入。页面维持现有桌面布局及红色品牌色。测试检查五个入口、展开状态、角色切换、原有数据统计入口与浏览器脚本错误。
