# 职工端 Web 改动的移动端适配设计

## 目标

将当前职工端 Web 原型新增的业务能力同步到移动端，同时保持移动端既有的信息架构和操作习惯。

## 同步范围

- 内容动态同步帖子图片展示与展开后的完整内容。
- “我的”同步个人发言、收藏、互动和发言进度相关变化。
- 发言进度详情同步新的帖子信息、当前状态和倒序时间线。
- 政策模块同步提问、我的提问及答复状态变化。
- 复用 Web 端当前数据和业务方法，移动端仅增加必要的布局与交互适配。

## 移动端约束

- 继续使用单列内容流、底部主导航、顶部返回栏和移动端详情页。
- 首页只保留欢迎信息、政策 Banner、内容分类和内容流。
- 不恢复此前从移动端首页删除的“通知公告”区块。
- 不恢复此前从移动端首页删除的“我的事项”或“我的进度”区块。
- 通知公告只从底部“公告”入口访问；个人进度只从“我的”访问。
- 不同步桌面登录页、桌面侧栏和右侧吸附栏等桌面专属视觉结构。

## 验收

- 移动首页不出现已删除业务区块。
- 新增业务入口在移动端可操作，详情、返回和弹层关闭正常。
- 帖子图片和进度详情在窄屏下无横向溢出或遮挡。
- Web 职工端现有功能不受影响。
