# 组织架构树表优化设计

参照用户提供的两张桌面截图，系统设置中的组织架构页采用紧凑的筛选栏、可展开树表和右侧行操作。保留职工端一致的红色强调色，不复制参考产品的蓝色品牌色。筛选包含组织名称、是否显示、状态，展开筛选可按上级组织过滤；工具栏提供全部收起、全部展开、新增、刷新。表格展示组织/机构、排序、是否显示、状态、创建时间、操作；行操作提供编辑和“更多”菜单中的新增下级、删除。

组织数据存入现有版本化浏览器演示数据，首次加载旧数据时仅补充组织数组，不重置已有帖子、事项和用户。树的父子关系由 parentId 表示，排序按同级 sort 字段；筛选时保留命中节点的祖先以展示路径。删除仅限叶节点，且禁止删除已被承办事项或账户引用的组织；移动组织时阻止将其设为自己或其后代。所有写操作记录进演示系统日志。正式系统的组织管理、授权和人事同步仍需服务端实现。
