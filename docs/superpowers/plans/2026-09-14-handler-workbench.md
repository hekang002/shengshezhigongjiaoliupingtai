# 承办工作台核心需求实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 将承办端工作台聚焦为待办统计、任务列表、条件筛选、剩余时限、事项详情和联系分办人六项核心能力，并与建言献策、心声诉求办理流程闭环。

**Architecture:** 复用现有管理端/承办端页面和浏览器本地原型数据模型，不新增移动端或独立登录页。工作台以状态驱动展示统计、列表操作和详情操作；建言献策、心声诉求共用组件，通过业务类型字段区分。

**Tech Stack:** 原生 HTML/CSS/JavaScript、现有 `管理端原型设计/app.js`、`管理端原型设计/workflow.js`、`prototype-data.js`、Playwright。

## Global Constraints

- 复用职工端登录页和红色视觉风格。
- 管理端仅保留桌面端页面。
- 敏感词不阻断建言献策和心声诉求进入办理流程。
- 转办只有在目标承办人点击“接收办理”后才生效。
- 只有当前最终承办人可更新进度和提交答复。
