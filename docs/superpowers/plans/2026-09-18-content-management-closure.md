# Content Management Closure Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Repair the content-management prototype so each module has a distinct responsibility and a coherent publication lifecycle.

**Architecture:** Keep the existing `workflow.js` page/router pattern and add small state objects plus shared publication helpers. Preserve the existing data model by deriving missing legacy statuses at render time and only writing explicit statuses when users perform new actions.

**Tech Stack:** Static HTML, CSS, vanilla JavaScript, `PrototypeData`, Playwright CLI.

## Global Constraints

- Do not change audit-management, assignment, or handler workflows except for the existing automatic echo creation after answer approval.
- Preserve existing worktree changes and do not commit.
- Use existing visual tokens and table/form patterns.
